# 📚 程序设计入门

## 程序与计算机
程序（Program）告诉计算机应如何完成一个计算任务，这里的计算可以是数学运算，比如解方程，也可以是符号运算，比如查找和替换文档中的某个单词。从根本上说，计算机是由数字电路组成的运算机器，只能对数字做运算，程序之所以能做符号运算，是因为符号在计算机内部也是用数字表示的。此外，程序还可以处理声音和图像，声音和图像在计算机内部必然也是用数字表示的，这些数字经过专门的硬件设备转换成人可以听到、看到的声音和图像。

程序由一系列指令（Instruction）组成，指令是指示计算机做某种运算的命令，通常包括以下几类：

输入（Input）：从键盘、文件或者其它设备获取数据。
输出（Output）：把数据显示到屏幕，或者存入一个文件，或者发送到其它设备。
基本运算：执行最基本的数学运算（加减乘除）和数据存取。
测试和分支：测试某个条件，然后根据不同的测试结果执行不同的后续指令。
循环：重复执行一系列操作。

对于程序来说，有上面这几类指令就足够了。程序是那么的复杂，而编写程序可以用的指令却只有这么简单的几种，所以编写程序理应是一件相当复杂的工作。编写程序可以说就是这样一个过程：把复杂的任务分解成子任务，把子任务再分解成更简单的任务，直到最后简单得可以用以上指令来完成。

编程语言（Programming Language）分为低级语言（Low-level Language）和高级语言（High-level Language）。机器语言（Machine Language）和汇编语言（Assembly Language）属于低级语言，直接用计算机指令编写程序。而C、C++、Java、Python等属于高级语言，用语句（Statement）编写程序，语句是计算机指令的抽象表示。举个例子，同样一个语句用C语言、汇编语言和机器语言分别表示如下：

| 编程语言 | 表示形式 |
|------|----------|
|C语言|a=b+1;|
|汇编语言|mov    0x804a01c,%eax <br> add    $0x1,%eax <br> mov    %eax,0x804a018|
|机器语言|a1 1c a0 04 08 <br> 83 c0 01 <br> a3 18 a0 04 08|

上表中的机器语言完全由十六进制数字组成。汇编语言把机器语言中一组一组的数字用助记符（Mnemonic）表示，直接用这些助记符写出汇编程序，然后让汇编器（Assembler）去查表把助记符替换成数字，也就把汇编语言翻译成了机器语言。从上面的例子可以看出，汇编语言和机器语言的指令是一一对应的，汇编语言有三条指令，机器语言也有三条指令，可见汇编器就是做一个简单的替换工作。

而C语言的语句和低级语言的指令之间不是简单的一一对应关系，一条a=b+1;语句要翻译成三条汇编或机器指令，这个过程称为编译（Compile），由编译器（Compiler）来完成，显然编译器的功能比汇编器要复杂得多。用C语言编写的程序必须经过编译转成机器指令才能被计算机执行，编译需要花一些时间，这是用高级语言编程的一个缺点，然而更多的是优点。首先，用C语言编程更容易，写出来的代码更紧凑，可读性更强，出了错也更容易改正。其次，C语言是可移植的（Portable）或者称为平台无关的（Platform Independent）。

平台这个词有很多种解释，可以指计算机体系结构（Architecture），也可以指操作系统（Operating System），也可以指开发平台。不同的计算机体系结构有不同的指令集（Instruction Set）。
计算机体系结构：指最底层的CPU使用的语言，对应不同的指令集架构（isa），比如x86、arm，以及新兴的RISC-V。
操作系统：指计算机使用的软件平台，当今桌面操作系统最常见的三巨头是Windows（你的电脑大概率是这一种），macOS（苹果电脑专属），以及你的计算机学习离不开的Linux操作系统（这才是你真正学习C语言、运行C程序所需要使用的操作系统）。
开发平台：一套工具，将高级语言（C/C++等）转换成能在特定平台上运行的程序，包括编辑器（Compiler）、汇编器（Assembler）、链接器（Linker）等。

## 终端

在此之前，也许你还没有接触过终端。但实际上终端才是你编译、运行C语言的场所。
终端，也常被称为命令行或控制台，本质上是一个**基于文本的交互界面**。在图形界面（如窗口、图标、鼠标点击）出现之前，这是操作电脑的主要方式。即便在今天，它依然是开发者工作中非常重要的一部分。

其核心工作逻辑是：
1.  **输入指令**：你通过键盘，在终端的光标处输入特定的**命令**。
2.  **执行程序**：按下回车键（Enter），终端会立即将你输入的命令传递给操作系统去执行。这个命令可以是一个程序的名字，也可以是一个复杂的操作指令。
3.  **输出结果**：操作系统完成指令后，会将执行的结果以纯文本的形式显示在终端窗口中，向你反馈。

在终端里，没有“双击”或“拖拽”的动作。你所有的操作，比如查看文件、运行程序或管理进程，都依靠输入精确的文本命令来完成。你需要时刻关注终端里的**当前路径**，因为大部分命令都是基于这个路径来定位文件和文件夹的。它的优势在于精确、高效，并且能让你清晰地看到每一步操作背后发生了什么。

### 终端初识：打开Windows终端
如果你此前没有打开过Windows终端，请你根据以下步骤完成：
1.在键盘上按下Win键，再按下R键，屏幕左下角将弹出一个窗口。
2.在弹出窗口中输入cmd或者powershell，按Enter确认。
3.如果你看到一个黑色窗口显示在屏幕上，恭喜你！你成功打开了Windows终端。

你已经成功打开了Windows终端，可这还远远不够。Linux操作系统的巨大优势就在于其终端集成了大量功能强大、标准统一且彼此可以协同工作的工具。接下来，你需要自己配置Linux环境了。

### 学会sudo
在Linux中，如果你发现某个操作需要超级用户的权限，那么在执行该操作之前加上 sudo。在使用 sudo 之前，你还应该将你的账户添加到 sudo 组中。不过，在此之前，你仍然需要先切换到 root 账户：
su -
Password:
请输入在安装过程中设定的 root 密码。请注意，为了避免密码泄露，这个密码不会在终端中显示。所以如果密码输错了，请你一直按删除直到你确保删除干净位置为止，再重新输入正确的密码。如果密码正确，你会看到提示信息发生变化：root@hostname:/home/username#
现在你可以将你的账户添加到 sudo 这个组中：
adduser "username" sudo  # 将username替换成你设定的用户名
exit
（建议在这里重启Linux操作系统）
在终端输入：whoami，预期输出你的用户名；输入：sudo whoami，预期输出“root”；输入：sudo apt-get update，这一条命令可能需要一定时间执行，待终端下一次显示“username@hostname:~$”说明该命令执行完毕。如果都成功，恭喜你完成了sudo初识！

### 配置C环境

## 运行你的第一个C程序
打开终端，输入：
```bash
code main.c
gedit main.c
```

你会打开对应的编辑器，并进入a.c文件编辑界面，输入以下代码：
```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

用 ctrl+s，保存后在终端编译执行：
```bash
$ gcc main.c
$ ./a.out
Hello, world.
```

gcc是Linux平台的C编译器，编译后在当前目录下生成可执行文件a.out，直接在命令行输入这个可执行文件的路径就可以执行它。如果不想把文件名叫a.out，可以用gcc的-o参数自己指定文件名：
```bash
$ gcc main.c -o main
$ ./main
Hello, world.
```

当你看到"Hello,world."显示在终端里，恭喜你完成了你的第一个C程序的编译、运行！你可能会感慨，这一路走来真的很不容易！是的，未来的路还有很长，这依然要依靠你的不懈努力来完成！
