# 📚 前言

> 刚踏入大学，很多同学对计算机了解不多，编程经验也有限，可能只接触过 Python 等语言。对于这些同学来说，大一的 C++ 程序设计课程可能会有些吃力，光靠自己摸索容易跟不上。
>
> 这份讲义就是为了帮助你 **快速入门 C++ 的前身—— C 语言**  。C 和 C++ 在很多地方是相通的，学好 C 语言，你的 C++ 课程作业和期末成绩都会轻松不少。

---

## 🎯 适用对象

- **大一新生**：想系统入门 C 语言，在课程中游刃有余
- **“一生一芯”学员**：请认真对待每一份讲义，**慎用 AI 工具**，所有代码务必保存到本地

---

## 🤖 关于 AI 工具的使用

在大模型时代，AI 已经渗透到学习和工作的方方面面。备战高考时你可能就用过各种 AI 工具，这很正常。**不要排斥使用 AI 来辅助学习**——借助 AI 写代码不意味着偷懒，关键在于你能否理解 AI 生成的内容。

请记住一条原则：**对自己的代码负责**。确保你完全理解每一行代码的含义，而不是机械地复制粘贴。
